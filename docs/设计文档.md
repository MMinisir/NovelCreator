# 小说创作辅助工具详细设计文档（修订版）

> 版本：2.0  
> 修订说明：本版本在 1.0 基础上，根据用户反馈与产品分析，重点解决“学习成本高、输入负担重、过度结构化抑制创意、AI 质量不稳定、本地存储丢失风险、移动端支持不足、可视化性能、编辑器功能基础、缺乏协作”等问题，同时强化“方法论驱动、结构化设定管理、AI 辅助定位、本地优先隐私安全”等核心优势。  
> 定位：本地优先、方法论驱动、面向中文小说创作者的设定管理与 AI 辅助写作工具，从“管理型工具”转向“服务型创作工作台”。

---

## 一、产品概述

### 1.1 产品定位

面向小说作者（尤其是长篇连载、网文、类型小说作者）的**创作工作台**，提供从设定管理、大纲规划、时间线梳理到 AI 辅助生成的一站式解决方案。产品以“结构化写作方法论”为核心，但强调“工具适配作者，而非作者适配工具”。支持**引导模式**与**自由模式**双模式，让结构成为可选的脚手架，而非束缚。

### 1.2 核心价值

- **设定不再混乱**：人物、地点、事件、关系、状态全部结构化存储，支持自动关联与智能提取，减少手动维护成本。
- **大纲有章可循**：内置雪花写作法、三幕式、角色弧光、网文黄金三章等成熟方法论，同时允许用户自定义方法论模板。
- **时间线直观可视**：解决长篇创作中时间错乱、事件顺序不清的痛点，模糊时间可手动调整排序。
- **AI 辅助而非替代**：AI 用于灵感激发、重复性劳动、一致性提醒和内容建议，不直接生成大段正文，所有输出均可编辑、可追溯。
- **本地优先，隐私安全**：所有数据默认存储在本地 IndexedDB，支持自动备份到本地文件及可选加密云盘同步，数据主权完全归用户。
- **多端覆盖**：桌面端深度创作，移动端快速记录与查看，数据互通。

### 1.3 目标用户

- 网文作者（起点、晋江、番茄等平台）
- 传统小说作者（出版、文学创作）
- 剧本杀 / 互动叙事创作者
- 同人创作者
- 合著团队与编辑协作场景

## 二、功能需求详述

### 2.1 项目管理

#### 2.1.1 项目列表

- 每个项目包含：书名、笔名/作者、类型（玄幻、都市、言情、悬疑等）、一句话简介、创建时间、最后修改时间。
- 支持项目封面图（本地图片或外链）。
- 支持项目搜索、排序、标签分类（如“连载中”“已完结”“构思中”）。
- 新增：**项目模板**：创建项目时可选“网文模板”“传统文学模板”“剧本杀模板”“空白模板”，自动初始化对应的大纲结构、字段和提示词库。

#### 2.1.2 项目设置

- **世界观设定**：力量体系、社会规则、种族、魔法/科技水平、历史背景等，以自由文本 + 标签形式存储。
- **叙事视角**：第一人称 / 第三人称 / 多视角等。
- **时间设定**：故事起始时间、时间流速（现实时间与故事时间比例）、是否允许模糊时间。
- **章节预设**：每章目标字数、章节命名规则（如“第X章 标题”）。
- **模式选择**：引导模式（默认，提供结构化流程）或自由模式（隐藏结构化字段，仅保留写作区和灵感笔记）。可随时切换，数据互通。

### 2.2 设定管理

#### 2.2.1 人物管理

**字段定义（保持1.0大部分字段，增加智能填充与自动跟踪）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 姓名 | 字符串 | 可设置多个别名；支持从正文中自动识别并创建 |
| 重要程度 | 枚举 | 主角 / 重要配角 / 配角 / 龙套 |
| 性别 / 年龄 | 字符串 | 支持模糊描述（如“外表20岁，实际300岁”） |
| 外貌描述 | 富文本 | 支持图片 |
| 性格标签 | 多选标签 | 可自定义标签体系（如 MBTI、九型人格、自定义） |
| 核心欲望 | 文本 | 角色最深层的动机；AI 小传生成时自动填充 |
| 致命缺陷 | 文本 | 角色性格弱点；AI 根据世界观生成建议 |
| 背景故事 | 富文本 | 包括出身、经历、关键转折 |
| 能力/技能 | 文本列表 | 可关联世界观设定 |
| 人物状态历史 | 数组 | 自动记录：用户标记状态变化时自动添加 |
| 角色弧光 | 数组 | 提供正向/负向/平弧模板，支持自定义阶段 |
| 出场记录 | 关联事件 | 自动统计：从章节文本或事件参与中提取 |
| 备注 | 富文本 | 作者自由填写 |

**新增特性：**

- **智能创建**：在写作区选中人名，右键“创建/关联人物”，自动提取上下文描述填入外貌、性格等字段，用户确认后保存。
- **快速录入**：任意页面输入 `@` 弹出快捷创建框，支持自然语言解析，如“@林夜，主角，废柴，隐忍，觉醒血脉”自动拆分为姓名、重要程度、性格标签、背景。
- **默认值填充**：基于项目世界观和大纲，AI 可为新人物推荐核心欲望、缺陷、能力等初始值。
- **人物卡片显示当前状态与最近变化**：卡片上直接显示“第10章：晋级金丹”，点击可跳转状态历史。

#### 2.2.2 人物关系

**关系模型（保持原有，增加自动建议与动态更新）：**

- 基础模型不变，新增：
  - 关系建立方式：手动、AI 建议、从正文检测。
  - 关系动态更新：当用户修改人物状态或事件结果时，可提示是否调整相关关系强度。

**UI 设计：**

- 关系列表视图：表格展示所有关系，支持筛选、排序。
- 关系图视图：力导向图，节点大小按重要程度，连线颜色按关系类型，连线粗细按强度绝对值。
- **新增**：关系图按需加载，双击节点聚焦子图，支持性能模式（关闭动画、标签）。
- **AI 关系建议**：在关系页面提供“获取建议”按钮，AI 基于人物列表生成可能的关系组合，用户可采纳或忽略。

#### 2.2.3 地点管理

**字段（保持1.0，增加自动关联）：**

- 名称、类型、描述、所属区域、关联人物、关联事件、图片。
- **新增**：地点可从正文或事件中自动提取，例如用户标记“家族大殿”后，系统自动创建地点并关联当前章节。

**UI 设计：**

- 地点卡片视图，支持按类型筛选。
- 地点详情页展示关联人物和事件列表。
- 可选地图视图（自定义上传背景图，标记地点位置）。

#### 2.2.4 事件管理

**字段（保持1.0，增加智能提取与快速创建）：**

- 名称、类型、描述、时间戳、参与者、地点、结果、关联伏笔、重要性、排序权重。
- **新增**：支持从正文中“提取事件”：选中一段描述，右键“提取为事件”，AI 自动分析时间、参与者、地点等信息并填充表单，用户确认后保存。

**UI 设计：**

- 事件列表按时间线排序展示。
- 事件详情页可查看参与者、地点、结果、关联伏笔。
- 支持从事件快速跳转到人物或地点详情。

### 2.3 大纲系统

#### 2.3.1 多级大纲结构

- **故事核**：核心冲突 / 核心问题，作为项目根节点。
- **五句话梗概**：对应三幕式结构（开端、发展、高潮、转折、结局），每句一句话。
- **分幕/分卷**：根据故事长度，可分为三幕或更多卷，每卷有标题和概要。
- **章节细纲**：每章包含标题、核心剧情概述、关键事件引用、出场人物、伏笔埋设/回收。
- **场景清单**：每章可拆分多个场景，每个场景包含：场景目标、地点、人物、冲突、结果。

**数据结构（保持原有，增加自由节点类型）：**

- 新增**自由节点**：可在大纲任意位置插入灵感碎片、备注、待办等，不强制符合结构。
- 支持多套大纲并存：例如“正式大纲”和“废稿大纲”，可切换查看。

**交互设计：**

- 树形大纲视图，支持展开/折叠、拖拽调整章节顺序、拖拽移动场景所属章节。
- 支持“一键生成五句话梗概”按钮（AI 辅助）。
- 章节节点显示关键事件标签、伏笔标签（未回收显示橙色，已回收显示绿色）。
- 大纲与正文分离，但可关联正文段落（如场景关联到具体正文文本）。
- **新增：大纲节点可转换为正文草稿**：右键章节节点“创建正文草稿”，自动生成带大纲摘要的空白文档。
- **新增：从正文反向生成大纲**：若作者先写正文，可一键从章节标题和段落摘要生成大纲结构。

### 2.4 时间线系统

#### 2.4.1 时间表示

- **精确时间**：`2024-03-15 14:30`
- **章节时间**：`第3章`
- **模糊时间**：`春天`、`三年后`、`大战结束后`、`主角成年时`
- **相对时间**：`事件A发生前三天`

系统支持将以上时间统一映射到可排序的数值或逻辑顺序，模糊时间通过用户手动调整顺序。**新增**：AI 可提供排序建议，用户确认后写入索引。

#### 2.4.2 全局时间线

- 垂直时间线展示所有事件，按时间顺序排列。
- 支持筛选：按人物、地点、事件类型、时间范围。
- 事件节点显示：事件名称、时间、参与者头像（小图标）、地点。
- 点击事件节点弹出详情卡片。

#### 2.4.3 角色时间线

- 选择某个人物，展示该人物参与的所有事件，按时间排序。
- 同时展示该人物的状态变化点（来自人物状态历史），与事件对应。
- 角色时间线可用于检查角色行为是否合理、成长弧线是否清晰。

#### 2.4.4 多轨时间线（高级）

- 按人物或地点或事件类型分轨展示，类似视频剪辑软件的时间轴。
- 支持缩放、平移，查看全局或细节。
- 轨道可折叠/展开。

**性能优化**：采用虚拟滚动与 Canvas 渲染，仅渲染可视区域，支持 2000+ 事件流畅滚动。

### 2.5 可视化功能

#### 2.5.1 人物关系图

- 力导向图，节点大小反映重要程度。
- 连线颜色：关系类型映射，连线粗细：关系强度绝对值。
- 连线标签：显示关系类型和强度。
- 交互：悬停显示摘要，点击打开详情侧边栏，双击高亮子图，拖拽调整布局，搜索定位。
- **新增**：按需加载：默认显示主角及直接关系，点击“展开全部”加载完整网络。
- **新增**：性能模式：关闭动画、标签、阴影，保证流畅。
- 导出：PNG / SVG。

#### 2.5.2 时间线图

- 全局时间线（垂直/水平可切换），颜色按事件类型区分。
- 支持缩放、平移、筛选搜索。
- 点击节点查看详情。

#### 2.5.3 大纲结构图（可选）

- 将大纲以思维导图形式展示，可折叠、展开节点。
- 支持导出为 OPML 或图片。

### 2.6 AI 辅助功能

#### 2.6.1 AI 服务基础架构

- **多模型支持**：OpenAI 兼容接口，可配置 DeepSeek、GPT、Claude、Kimi、通义千问等。
- **统一上下文构建器**：自动收集相关数据（项目设定、人物列表、已有大纲等）构建 Prompt 上下文。
- **流式输出**：支持 SSE 流式返回。
- **温度控制**：设定类生成 0.3-0.5，创意类 0.7-1.0。
- **Token 管理**：自动估算，超长时截断或摘要。
- **新增**：
  - **结果对比**：同一请求可同时调用多个模型或多次生成，并列展示供选择。
  - **提示词预览**：调用前显示将使用的完整 Prompt 和上下文，高级用户可临时修改。
  - **本地缓存**：相同请求和参数的结果缓存，减少重复 API 调用。
  - **AI 建议可追溯**：每条生成结果记录输入上下文和提示词版本，可回看。

#### 2.6.2 AI 功能列表

保持 1.0 所有功能，并做以下增强：

1. **生成故事核与五句话梗概**：增加“参考同类作品”选项，可输入参考书名或风格。
2. **生成人物小传**：在原有基础上，增加“缺陷影响行为”的具体示例，使人物更立体。
3. **生成人物关系建议**：输出时包含“关系变化节点”和“冲突潜力”。
4. **生成时间线**：自动识别模糊时间并给出排序建议，支持 JSON 导入。
5. **大纲扩展**：可根据选择的方法论模板（三幕式、英雄之旅、网文黄金三章等）输出对应结构。
6. **场景生成**：输出关键描写片段、对话要点、动作节拍，**不输出完整正文**。
7. **伏笔检测与建议**：从文本中识别可复用细节，并建议回收时机。
8. **一致性检查**：结合规则引擎与 LLM，输出结构化报告。
9. **润色与改写**：支持风格自定义，并新增“口语化/书面化”“网文节奏优化”等预设。

**新增功能**：

10. **AI 审稿**：对章节进行结构、节奏、文笔分析，给出评分和改进建议，但不直接修改。
11. **故事体检报告**：综合人物弧光完成度、伏笔回收率、时间线连贯性、设定利用率，生成项目健康度报告。
12. **智能提取导入**：从已有文本中批量提取人物、地点、事件、伏笔候选，用户确认后导入。

#### 2.6.3 提示词管理

- **提示词模板库**：内置多个高质量模板，按功能分类，经过测试并标注适用场景。
- **变量系统**：模板中可使用变量，运行时自动替换。
- **可视化模板编辑器**：提供表单式编辑器，用户通过下拉框和输入框组合提示词，自动生成模板文本；高级用户可切换代码模式。
- **自定义模板**：可创建、编辑、删除模板，支持导出/导入 JSON。
- **版本管理**：记录模板修改历史，可回滚。
- **模板分享**：支持导出/导入 JSON，未来可接入社区。

### 2.7 伏笔管理系统

**数据模型（保持1.0）**，增强：

- **自动检测**：AI 扫描正文，标记可能成为伏笔的细节（反复出现的物品、未解释的对话、异常行为），生成候选伏笔列表。
- **回收提醒**：当章节进度接近预期回收时间，写作区侧边栏提示“本章适合回收伏笔：神秘戒指”。
- **伏笔状态自动更新**：当用户在正文中标记回收时，自动更新伏笔状态和回收位置。
- **超期提醒**：活跃伏笔超过预期回收章节时，首页显示提醒。

### 2.8 写作区与正文管理

#### 2.8.1 写作界面

- 分屏模式：左侧大纲/设定参考，右侧编辑器；参考面板可关闭或最小化。
- 编辑器支持 Markdown 语法，实时预览，并扩展支持：
  - 章内场景标签，关联正文段落到具体场景。
  - 行内评论与批注（适用于审阅）。
  - 聚焦模式、打字机模式。
  - 自定义样式模板（网文排版、出版排版等）。
  - 表格、图片、脚注。
- 自动保存到 IndexedDB，记录修改历史。

#### 2.8.2 章节管理

- 章节列表与大纲章节对应，支持章节状态（未开始/草稿/已完成/已修改）。
- 字数统计、目标字数进度条。
- 版本历史：保存手动/自动保存版本，支持可视化差异对比和回滚（类似 Git diff）。

#### 2.8.3 一致性提醒（写作时）

- 在写作过程中，侧边栏实时显示当前场景相关设定：人物当前状态、地点描述、关联伏笔。
- **智能冲突检测**：输入文字涉及设定冲突时（如人物突然使用未设定能力），即时提示。
- **伏笔回收提示**：当检测到可能回收某伏笔的文本时，询问是否标记回收。

### 2.9 导入导出与数据管理

#### 2.9.1 导入

- 支持从 TXT、Markdown、JSON、DOCX 导入正文或设定。
- **智能解析导入**：可解析特定格式（如 `@人物: 姓名, 重要程度, 描述`）或从文本中自动提取人物、地点、事件候选。
- 导入正文时自动按章节标题拆分，并可选择自动生成大纲。

#### 2.9.2 导出

- 导出整个项目为 JSON（包含所有设定、大纲、正文）。
- 导出正文为 TXT / Markdown / DOCX / EPUB / PDF（带排版样式）。
- 导出人物关系图为 PNG / SVG。
- 导出时间线为图片或 CSV。
- 导出大纲为 Markdown 或 OPML。
- **新增**：导出设定集为独立的 HTML 或 PDF，便于打印查阅。

#### 2.9.3 数据备份与恢复

- **自动本地备份**：每 30 分钟或关闭项目时，自动下载加密 JSON 备份到用户指定文件夹（通过 File System Access API）。
- **手动备份**：一键导出完整 JSON，可设置密码保护。
- **恢复**：从任意备份文件导入，支持完整性校验和版本时间线选择。
- **云盘同步**：用户可绑定自己的 WebDAV/坚果云/Dropbox，工具将加密数据包同步到指定目录，实现多设备准同步；处理冲突时基于操作日志和时间戳合并。
- **存储配额管理**：监控 IndexedDB 使用量，接近上限时提醒清理旧版本或导出。

### 2.10 移动端（PWA）

- **移动端功能**：
  - 快速记录灵感（文本、语音转文字、拍照）。
  - 查看人物卡、大纲、时间线、伏笔列表。
  - 简单章节编辑（支持 Markdown 基础语法）。
  - 接收一致性提醒和伏笔提醒。
- **数据同步**：通过云盘同步或局域网文件传输与桌面端保持一致。
- **离线支持**：PWA 缓存最近项目，离线可查看和记录，联网后同步。

### 2.11 写作数据分析（可选）

- 字数统计、日均字数、每章字数分布。
- 人物出场频率、设定利用率分析。
- 章节节奏分析（基于事件密度和冲突强度），提示连续平淡章节。
- **新增**：故事健康度报告（结合一致性检查、伏笔回收率、人物弧光完整性）。

### 2.12 协作功能（基于文件同步）

- **异步协作**：项目数据为单个 JSON 文件，可通过 Git、坚果云等版本控制工具共享；内置冲突检测与合并向导。
- **评论与审阅模式**：在正文中添加评论、建议修改、批注，适合编辑与作者沟通。
- **权限管理**：基于文件共享，可设置只读、评论、编辑权限（通过不同同步工具实现）。
- **不提供中心化服务器**，保持数据主权。

## 五、技术架构细化

### 5.1 前端架构

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **UI 库**：Tailwind CSS + Headless UI / Radix UI
- **状态管理**：Zustand + Immer
- **路由**：React Router
- **可视化**：
  - 关系图：优先使用 Cytoscape.js 或 Sigma.js（Canvas/WebGL），支持按需加载和性能模式。
  - 时间线：自研虚拟滚动组件，初期垂直列表，后期 Canvas 多轨。
  - 图表：Recharts。
- **编辑器**：TipTap（ProseMirror），扩展批注、场景标签、版本对比。
- **存储**：Dexie.js（IndexedDB 封装），结合 File System Access API 进行自动备份。
- **PWA**：使用 Workbox 实现离线缓存。

### 5.2 数据存储设计

保持 1.0 的 Object Stores，新增：

| Store 名称 | 主键 | 说明 |
|-----------|------|------|
| idea_fragments | id | 灵感碎片 |
| comments | id | 评论与批注 |
| backup_metadata | id | 备份元数据 |
| prompt_template_versions | id | 提示词版本 |
| sync_status | projectId | 同步状态记录 |

所有数据均以 JSON 序列化，便于导出导入。数据迁移策略保持原有。

### 5.3 AI 服务层

- 抽象 `AIProvider` 接口，实现 OpenAI 兼容 Provider。
- 上下文构建器增强：支持多模型调用、结果缓存、提示词预览。
- Token 估算使用 `gpt-tokenizer`，超长自动摘要。
- 结果对比模块：支持并行请求多个模型或多次生成。

### 5.4 离线与同步

- 所有功能离线可用（除 AI 生成需要网络）。
- 自动本地备份与恢复。
- 可选云盘同步：实现 WebDAV 客户端，支持加密上传下载，冲突合并基于操作日志。
- 移动端 PWA 与桌面端通过同步文件保持一致。

## 六、交互设计要点

### 6.1 全局布局

- 左侧导航栏：项目、人物、地点、事件、大纲、时间线、关系图、伏笔、写作区、灵感碎片、设置。
- 顶部工具栏：项目切换、全局搜索、导入导出、AI 助手入口、模式切换（引导/自由）。
- 主内容区：根据导航切换。
- 右侧浮动面板：当前选中项快速详情、AI 建议、一致性提醒。

### 6.2 关键交互流程

#### 流程 1：新建项目并生成大纲（优化）

1. 点击“新建项目”，选择项目模板（网文/传统/空白），填写书名、类型、一句话灵感。
2. 进入“故事核”页面，按引导填写五个问题（可跳过或自由填写）。
3. 点击“AI 生成五句话梗概”，选择参考模板（三幕式/英雄之旅等），系统调用 AI，返回结果填入输入框，用户可编辑。
4. 点击“生成分幕”，AI 基于梗概生成多幕概要。
5. 用户手动调整或继续“AI 生成章节细纲”。
6. 大纲树生成，用户可拖拽调整，也可切换到自由模式直接写作。

#### 流程 2：从正文提取设定（新）

1. 在写作区粘贴或输入一段文本。
2. 点击“智能提取”，选择提取类型（人物/地点/事件/伏笔/时间线）。
3. AI 分析文本，返回候选列表，用户勾选确认。
4. 系统自动创建设定条目并关联到当前章节。
5. 时间线、关系图等自动更新。

#### 流程 3：快速记录灵感（新）

1. 任意页面按 `@` 或点击“灵感碎片”。
2. 输入文本或语音，可添加标签（人物/情节/对话等）。
3. 灵感碎片存入独立区域，之后可拖入大纲或正文。

#### 流程 4：伏笔管理（优化）

1. 写作时选中文字，右键“标记为伏笔”或“检测伏笔”。
2. 填写/确认伏笔描述、预期回收章节。
3. 伏笔出现在列表和时间线上。
4. 当章节进度接近预期回收时间，侧边栏提示。
5. 回收时选中文字，右键“标记为回收”，选择对应伏笔。

### 6.3 搜索与过滤

- 全局搜索：支持搜索人物、地点、事件、大纲、正文、灵感碎片。
- 高级过滤：按类型、标签、时间范围、状态过滤。
- 搜索结果高亮显示。

## 七、非功能需求

### 7.1 性能

- 人物 ≤ 500，事件 ≤ 2000，章节 ≤ 1000 时，界面流畅（60fps）。
- 关系图 500 节点流畅（使用按需加载与性能模式）。
- 时间线 2000 事件延迟 < 1s（虚拟滚动）。
- 自动备份不影响前台操作（后台执行）。

### 7.2 兼容性

- 支持最新版 Chrome、Edge、Firefox、Safari。
- 桌面端优先，移动端提供 PWA 查看与速记功能。
- 支持 File System Access API（Chrome/Edge），其他浏览器降级为手动下载备份。

### 7.3 安全性

- 数据默认本地存储，AI 调用使用用户配置的 API Key，不经过中间服务器。
- 支持加密导出（密码保护）。
- 云盘同步传输加密数据。

### 7.4 可扩展性

- 数据模型预留自定义字段。
- 插件式提示词模板与方法论引擎。
- 未来可开放社区共享模板和插件。

## 八、实现注意事项与风险应对

### 8.1 数据模型演进的灵活性

保持 JSON 存储，提供迁移函数，数据修复工具重建索引。

### 8.2 AI 生成质量不稳定

- 所有 AI 输出可编辑，提供多结果对比和重新生成。
- 调用前预览提示词，用户可调整。
- 结果缓存和版本记录，便于回退。

### 8.3 用户维护成本过高

- 减少必填字段，支持智能提取、快速录入、自动跟踪。
- 提供自由模式，隐藏结构化字段。
- 移动端支持语音速记。

### 8.4 与现有工具差异化

- 方法论引擎 + 服务型工作台。
- 本地优先 + 可选云盘同步。
- AI 定位为编辑助手，不替代创作。

### 8.5 移动端与桌面端数据冲突

- 基于操作日志和时间戳合并，冲突时提供可视化合并向导。
- 建议用户在同一时间只在一端编辑，或通过云盘同步解决。
